**PR Title Format**: &lt;type&gt;: &lt;short description&gt; (#&lt;issue-number&gt;)

*Example:*

*feat: build add dormitory frontend form (#14)*

*fix: resolve 500 error on manager login middleware (#22)*

*chore: update prisma schema for tenant contracts (#8)*

*feat: integrate final tailwind color palette variables (#3)*
